# NekoMaki — English Dark Portfolio

A static, responsive portfolio converted from https://dreamhigh.vercel.app/.

## Files
- `index.html` — complete portfolio content and project gallery
- `styles.css` — dark theme, responsive layout, and visual styling
- `script.js` — mobile navigation and project category filters

## Run locally
Open `index.html` in a browser. No build step, package manager, framework, or JavaScript modules are required.

## Images
The portfolio references the original image assets hosted by `dreamhigh.vercel.app` so the same images are used without duplicating or altering them. An internet connection is required for those images to load. If you want a fully offline copy, download the referenced image files from the original site and place them in a local `assets/` folder, then update the image `src` paths in `index.html`.

## Contact
The contact CTA opens the visitor's email client and addresses `ddreamhhigh@gmail.com`. The original portfolio displayed a contact form, but no form-processing endpoint was exposed in the public page, so this static version uses a direct email link rather than pretending a form submission is connected.
